Use at your own risk. These calculators were built and checked by one person (me) — they have not been independently reviewed. Each tool includes the source chart it was built from so you can verify any result by hand. If you find something that looks wrong, please let me know.

Every tool here is beta. Each one carries a BETA tag for that reason — treat every number as provisional and check it against the source chart shown inside the tool before you fly it.

Ideas for improvements are also welcome — email ghock@achi-tx.com.
